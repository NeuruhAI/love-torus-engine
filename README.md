# Horn Torus Dynamical Engine

Zero-dependency Python dynamical model and real-time Three.js WebGL particle emitter.

## Live Demo
https://neuruhai.github.io/love-torus-engine/

## Run Locally

    python3 love_torus.py
    python3 love_torus.py --substeps 200 --export trajectory.json
    python3 -m http.server 8000
